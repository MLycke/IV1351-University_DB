# Database Project – KTH IV1351

## Description
This project contains the database for the course layout and teaching load allocation assignment in KTH's IV1351 course.

The database is implemented using PostgreSQL and managed with pgAdmin 4.

## Contents
- `sql/schema.sql` – SQL statements for creating the database tables, primary keys, and foreign keys.
- `sql/test_data.sql` – SQL statements for inserting test data.

## Requirements
- PostgreSQL
- pgAdmin 4 (optional, for database management)

## Setup
1. Create a new database in PostgreSQL.
2. Open the database in pgAdmin 4.
3. Run `sql/schema.sql` to create the tables and relationships.
4. Run `sql/test_data.sql` to insert the test data.

## Notes
The test data is fictional and is used for testing the database and its relationships.
